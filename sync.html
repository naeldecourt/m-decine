Synchronisation

Pour retrouver ta progression sur ton téléphone comme sur ton ordinateur. Sans configuration, le site fonctionne très bien : tes données restent simplement sur l'appareil où tu les as saisies.

État —

Renseigne ci-dessous un projet Firebase pour activer la synchronisation.

1. Le projet Firebase

  1. Crée un projet gratuit sur console.firebase.google.com.
  2. Dans Authentication, active le fournisseur E-mail/Mot de passe.
  3. Dans Firestore Database, crée une base en mode production.
  4. Dans Règles, colle les règles données à l'étape 3.
  5. Dans Paramètres du projet → Vos applications → Web, copie le bloc firebaseConfig et colle-le ici.

Ces clés sont publiques par nature : ce sont les règles Firestore de l'étape 3 qui protègent tes données. Elles ne sont stockées que dans ce navigateur, jamais dans le dépôt.

2. Ton compte

Le même couple e-mail / mot de passe sur chaque appareil : c'est lui qui relie ton téléphone à ton ordinateur. Le compte est créé automatiquement à la première connexion.

3. Les règles Firestore

À coller dans Firestore Database → Règles. Elles n'autorisent chaque compte qu'à lire et écrire son propre document.

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /utilisateurs/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}

Comment la fusion se comporte. Deux appareils qui ont travaillé chacun de leur côté ne s'écrasent pas : les tours de révision des deux sont réunis, sans doublon — un tour n'est jamais perdu. Pour ce qui ne peut avoir qu'une valeur (réglages, notes, séances du calendrier), c'est la version la plus récente qui l'emporte.

Sans réseau, tu continues de travailler normalement : les modifications partent à la prochaine connexion.

Tu préfères éviter le cloud ? L'export et l'import JSON de la liste des items font le même travail à la main : un fichier à exporter d'un côté, à importer de l'autre.
